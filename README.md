# Netrion

**Ideas que se convierten en presencia digital.**

Netrion es un proyecto enfocado en el desarrollo de soluciones web para negocios y marcas que buscan fortalecer su presencia digital.

## Servicios

- **Página Web Informativa:** presentación de negocios, servicios y medios de contacto.
- **Sitio Web Multipágina:** organización de información en diferentes secciones.
- **Tienda Virtual:** soluciones digitales para mostrar productos y gestionar pedidos.

## Características

- Diseño adaptable a dispositivos móviles y escritorio.
- Navegación intuitiva.
- Presentación de servicios y proyectos conceptuales.
- Formulario de solicitud de cotización.
- Contacto directo mediante WhatsApp.
- Optimización de carga y recursos visuales.

## Tecnologías

- React
- Vite
- JavaScript
- HTML5
- CSS3
